# 🎬 Shorts Factory – מערכת אוטומציה חינמית ליצירת חומרי גלם ל-YouTube Shorts

מערכת אוטומציה שכתובה ב-Python שמייצרת **חומרי גלם מוכנים להפקה** עבור YouTube Shorts –
רעיונות וכותרות ויראליות, תסריט עד 50 שניות, פרומפטים מדויקים באנגלית לכלי וידאו
חינמיים, חבילת SEO מלאה (כותרת, תיאור, 15 תגיות והאשטאגים), וקובץ קריינות MP3.

> 🌐 **גרסה חדשה – אתר אינטרנט:** כל התהליך זמין גם מממשק ווב מודרני
> (דפדפן + שרת FastAPI). ראו סעיף "גרסת הווב" להלן.

> ✅ **100% חינם.** אין כאן שום כלי שמחייב כרטיס אשראי או מפתח API בתשלום.
> הטקסט נוצר בעזרת Groq (מסלול חינמי אמיתי עם מודלי Llama), והקריינות נוצרת
> עם הספרייה החינמית gTTS.

## 📋 מה המערכת עושה – 4 שלבים

| שלב | תיאור | טכנולוגיה |
|-----|-------|-----------|
| **1** | מקבלת נושא כללי מטרמינל, מייצרת 5 רעיונות וכותרות קליטות, ומציגה אותם לבחירה (1-5) | Groq API – Llama |
| **2** | מייצרת תסריט קצב וקצר (עד 50 שנ׳), 3-4 סצנות ויזואליות עם פרומפטים באנגלית, וניתוח SEO (כותרת, תיאור, 15 תגיות, האשטאגים) | Groq API – Llama |
| **3** | ממירה את התסריט לקובץ קריינות MP3 ושומרת אותו בתיקיית הרעיון | gTTS (חינם) |
| **4** | כותבת `Script_Metadata.txt` מסודר עם התסריט, הפרומפטים והתגיות + `content.json` | Python |

## 🔑 הגדרת מפתח ה-API של Groq

1. צרו מפתח חינמי ב-<https://console.groq.com/keys> (הוא מתחיל ב-`gsk_...`).
2. הגדירו אותו כמשתנה סביבה:

**לינוקס / macOS (לסשן הנוכחי):**

```bash
export GROQ_API_KEY="gsk_..."
```

**לינוקס / macOS (קבוע):**

```bash
echo 'export GROQ_API_KEY="gsk_..."' >> ~/.bashrc && source ~/.bashrc
```

**ווינדוס (CMD):**

```cmd
set GROQ_API_KEY=gsk_...
```

**ווינדוס (PowerShell):**

```powershell
$env:GROQ_API_KEY="gsk_..."
```

**חלופה נוחה – קובץ `.env`:** העתיקו את `.env.example` ל-`.env` וערכו אותו. הקובץ
נטען אוטומטית בכל הפעלה (לא דורס משתני סביעה שכבר הוגדרו).

```bash
cp .env.example .env
nano .env
```

> ⚠️ **אבטחה:** אל תעלו קובץ `.env` ל-Git (הוא כבר ב-`.gitignore`), ואל תפרסמו
> את המפתח בקוד או בצילומי מסך.

## 🚀 הפעלה

```bash
python main.py
```

המערכת תשאל אתכם על נושא, תייצר 5 רעיונות, ותציג אותם. הזינו את המספר של הרעיון
המנצח (1-5) – ומכאן והלאה הכל אוטומטי.

### דוגמאות נוספות

```bash
python main.py -t "טיפים לחיסכון בכסף"       # עם נושא מראש
python main.py -t "כושר ביתי" -n 5 -o ./out  # 5 רעיונות, תיקיית פלט מותאמת
python main.py --skip-audio -t "בישול מהיר"  # בלי להפיק קובץ שמע
python main.py --check                       # בדיקת מפתח API ורשימת מודלים
python main.py --help                        # כל האפשרויות
```

### דגלים זמינים

| דגל | תפקיד |
|-----|-------|
| `-t, --topic` | נושא כללי (מדלג על השאלה האינטראקטיבית) |
| `-n, --ideas N` | מספר רעיונות (3-8, ברירת מחדל: 5) |
| `-m, --model` | מודל Groq (ברירת מחדל: `llama-3.3-70b-versatile`) |
| `-o, --output-dir` | תיקיית הפלט הבסיסית (ברירת מחדל: `output/`) |
| `--tts-lang` | שפת הקריינות (`iw` = עברית, `en` = אנגלית) |
| `--slow-tts` | הקרניה איטית יותר |
| `--skip-audio` | דילוג על הפקת ה-MP3 |
| `--check` | בדיקת מפתח ה-API ורשימת המודלים הזמינים |
| `--no-color` | השבתת צבעים |
| `-v, --verbose` | לוג מפורט (DEBUG) |

| משתנה | ברירת מחדל | הסבר |

### מודלים חינמיים ב-Groq (נבדק אוקטובר 2026)

* `moonshotai/kimi-k2-instruct`
* `llama-3.1-8b-instant` – הנפח הגבוה ביותר (~14,400 בקשות/יום)

## 🌐 גרסת הווב (אתר אינטרנט)

למי שמעדיף ממשק גראפי במקום טרמינל – יש **אתר מלא**: מזינים מפתח API ונושא בדפדפן,
ובוחרים רעיון בלחיצה. הכל עובד דרך שרת מקומי (FastAPI) שמבצע את הקריאות ל-Groq ו-gTTS.

### הפעלה

```bash
pip install -r requirements-web.txt
python webapp/server.py          # או: uvicorn webapp.server:app --reload
```

ואז פתחו בדפדפן: **http://127.0.0.1:8000**

### איך זה עובד

| רכיב | תפקיד |
|------|-------|
| `webapp/server.py` | שרת FastAPI: מקבל את המפתח מהדפדפן (כותרת `X-Groq-API-Key`), קורא ל-Groq ול-gTTS, ומייצר את הקבצים |
| `webapp/static/index.html` | ממשק הווב (4 שלבים: מפתח ← נושא ← רעיון ← תוצאות) |
| `webapp/static/app.js` | לוגיקת הדפדפן (קריאות fetch, העתקה ללוח, הורדות) |
| `webapp/static/style.css` | עיצוב כהה ותומך RTL |

### נקודות הקצה (API)

| Endpoint | תפקיד |
|----------|-------|
| `GET /api/health` | בדיקת תקינות השרת |
| `POST /api/check` | בדיקת המפתח מול Groq + רשימת מודלים |
| `POST /api/ideas` | שלב 1 – 5 רעיונות לנושא |
| `POST /api/content` | שלב 2 – תסריט + פרומפטים + SEO |
| `POST /api/project` | שלבים 3+4 – הפקת שמע + כתיבת הקבצים |
| `GET /api/files/{token}/{filename}` | הורדת voiceover.mp3 / Script_Metadata.txt / content.json |

### למה צריך שרת (ולא לקרוא ל-Groq ישירות מהדפדפן)?

1. **Groq אינו תומך ב-CORS** – קריאה ישירה מהדפדפן תיחסם.
2. **המפתח נשאר אצלכם** – הוא נשלח רק לשרת *המקומי שלך*, לא נשמר לדיסק ולא נכתב ללוגים.
3. **gTTS וקבצים** דורשים גישה למערכת הקבצים – שקיימת רק בצד השרת.

### הגדרות מתקדמות

```bash
# מפתח קבוע בשרת (אז אין צורך להזין אותו כל פעם באתר)
export GROQ_API_KEY="gsk_..."
python webapp/server.py

# שינוי פורט / תיקיית פלט
PORT=9000 SHORTS_OUTPUT_DIR=./my_projects python webapp/server.py
```
